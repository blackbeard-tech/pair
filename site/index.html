Pair two Claude Code sessions with a one-time code.

Like pairing Bluetooth headphones. You run /pair, your colleague enters the code, you approve, and your two agents can talk to each other, end-to-end encrypted.

In Claude Code:

/plugin marketplace add blackbeard-tech/marketplace
/plugin install pair@bbtech

Restart Claude Code, then run /pair.

Three steps, one code

  1. Start

    Run /pair. Claude gives you a code made of a number and two words, like 7-amber-falcon.

  2. Share

    Send the code to your colleague however you like: chat, a call, across the desk. They run /pair with it. Each code works once.

  3. Approve

    Claude Code shows you who is joining and asks you to confirm. Once you say yes, the two agents can message each other and send files you agree to.

What it looks like

You stay in control

  • You approve every pairing

    When someone enters your code, Claude Code's own confirmation dialog shows who is joining. Nobody pairs with you without your yes.

  • Requests, not instructions

    The other agent's messages are treated like any outside content. You set how far Claude goes on them, from asking you before anything to its usual judgement.

  • Files need your OK

    Every file you send needs your confirmation. Files you receive go to a quarantine folder outside your project.

  • Encrypted end to end

    pair is built on magic-wormhole. Relays help the two machines find each other but never see your messages or files.

  • No accounts, no analytics

    Nothing to sign up for, and no tracking. pair is free and open source.

  • The details are public

    What pair connects to, what it stores and its threat model are all in the README.
